# Daily Trading Checklist

## Pre-Session (30 min before)

- [ ] Check economic calendar (ForexFactory / CoinMarketCal)
- [ ] Review overnight price action on 1H chart
- [ ] Mark key 1H levels: support, resistance, EMA 50
- [ ] Note daily VWAP position
- [ ] Check ByBit funding rates
- [ ] Check BTC dominance trend (if trading alts)
- [ ] Determine session bias: **LONG / SHORT / NO TRADE**
- [ ] Account balance: $______
- [ ] Max daily loss (5%): $______
- [ ] Max risk per trade (2%): $______

## Pre-Trade Checklist (Before every entry)

### Trend Alignment
- [ ] 1H price vs EMA 50: above (long) / below (short)
- [ ] 1H EMA 50 slope: favorable
- [ ] 1H RSI: confirms direction

### Momentum
- [ ] 15M EMA 9 vs EMA 21: aligned with trade
- [ ] 15M RSI: confirms direction

### Entry Trigger (5M)
- [ ] EMA 9/21 cross — OR — EMA 21 pullback — OR — VWAP bounce
- [ ] RSI in valid range (40-65 long / 35-60 short)
- [ ] Volume above 20-period MA
- [ ] No major S/R within 1 ATR in trade direction

### Risk Check
- [ ] Position size calculated (use position_calculator.py)
- [ ] Stop loss placed at logical level
- [ ] R:R >= 1.5:1
- [ ] Within daily trade limit (max 4)
- [ ] Within daily loss limit
- [ ] Emotionally calm and focused

## Post-Session (15 min after)

- [ ] Log all trades in journal
- [ ] Calculate daily P&L
- [ ] Review each trade: entry quality, exit quality
- [ ] Note one thing that went well
- [ ] Note one thing to improve
- [ ] Update account balance
- [ ] Close charts — done for the day
